unpacks every enabled plugin before the backend starts. Watch it with

  kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/instance={{ .Release.Name }} -c install-dynamic-plugins -f

If sign-in fails with "unable to resolve user identity", the GitHub login has no
matching User entity in the catalog. Add it to examples/org.yaml, or enable
GithubOrgEntityProvider — see deploy/helm/rhdh/README.md.
